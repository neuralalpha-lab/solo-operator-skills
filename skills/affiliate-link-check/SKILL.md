# アフィリエイトのリンクと表示の点検

## 前提
- 法律や各プログラムの規約の最終判断はしない。「要確認」とし、次の一次情報を見るよう促す。
  - ステルスマーケティング規制・景品表示法：消費者庁の最新の案内
  - 各アフィリエイトサービス（ASP）・各プログラム（Amazon アソシエイトなど）：契約・規約・ガイドラインの最新版
  - 公開先の販路（ブログサービス・動画・SNS）の広告・外部誘導のルール
- 確認できなかった項目は「未確認」と書く。

## 進め方
1. 点検するもの（本文・説明欄・投稿文）と、使っているプログラム名を聞く。
2. 下の項目を「OK／要修正／未確認」で判定する。
3. 要修正は直し案を出す。最後に件数をまとめる。

## 点検項目
### 表示
- [ ] 報酬を得るリンクを含むなら、読者がすぐ気づく位置（冒頭、動画なら説明欄の先頭と、できれば映像・音声でも）に「【PR】」「広告」など、広告と分かる表示があるか
- [ ] 表示が小さい・薄い・折りたたまれた中・記事の最後だけ、になっていないか
- [ ] プログラムが定型文を求める場合（例：Amazon アソシエイトの表記）、最新の規約どおりの文言を入れているか。文言は各プログラムの規約で確認する（記憶で書かない）
- [ ] 「PR ではありません」「純粋な感想です」など、実際と異なる説明をしていないか

### リンク
- [ ] リンク先が正しい商品・サービスか。切れていないか、在庫切れ・終了していないか
- [ ] リンクの短縮や隠しで、広告リンクだと分からなくなっていないか（プログラムの規約で許可されているか確認）
- [ ] 自分で自分のリンクをクリックして購入するなど、規約で禁止されがちな行為を勧めていないか
- [ ] プログラムが禁止する掲載場所（メール、特定の SNS、ダウンロード資料など）に貼っていないか

### 内容
- [ ] 商品・サービスについて、実際に使っていないのに使ったように書いていないか
- [ ] 根拠のない数字（「9割が満足」など）や効果の約束（「必ず」「誰でも」）がないか
- [ ] 価格・割引・ポイント還元の表記は、時点と条件が分かるか。変わりやすい情報は「執筆時点」と書くか、書かない
- [ ] 比較記事で、報酬の高い方だけを不当に良く書いていないか。デメリットも事実の範囲で書いているか
- [ ] 健康・美容・金融などの話題は、`jp-publish-check` で薬機法・金融の注意も点検する

## 出力の形
```
点検結果：OK ◯件／要修正 ◯件／未確認 ◯件
要修正：（場所・理由・直し案）
未確認：（何を、どの規約・一次情報で確かめるか）
```

## 禁止
- 「この表示で法的に問題ありません」と断定する。
- 表示を目立たなくする方向の提案をする。
