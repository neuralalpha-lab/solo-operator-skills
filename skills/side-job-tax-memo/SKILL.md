# 副業の確定申告：準備メモの作り方

## 最初に伝えること（毎回）
- このスキルは、書類と記録を整理するためのメモ作りの手伝いで、税務の助言ではない。
- 税額の計算、所得の区分（事業所得・雑所得など）、申告が必要かの判断、控除や経費にできるかの判断はしない。個々の事情で変わるため、国税庁の最新の案内（国税庁ウェブサイト・確定申告の特設ページ）か、税務署・税理士に確認するよう促す。
- 制度・金額の基準・提出方法は年によって変わる。メモに書く制度の話は「一般的に言われていること」とし、必ず「最新は国税庁で確認」と添える。断定しない。

## 進め方
1. **対象の年を確認**する（何年分か）。
2. 次を聞く（分からなければ「不明」でよい）。
   - 収入の種類（例：広告収入、アフィリエイト、販売プラットフォームの売上、業務委託の報酬、給与の有無）
   - 入金先（どの口座・どのサービス）
   - 帳簿・記録のつけ方（表計算、会計ソフト、なし）
   - 経費になりそうな支出の種類（本人の見立てでよい）
   - 本業の勤め先で給与以外の手続き（年末調整済みか）があるか
3. 下の「記録の整理」「集める書類」を、相手の状況に合わせた一覧にする。
4. 最後に「専門家・国税庁に確認したいこと」を一覧にして渡す。

## 記録の整理（一般的な考え方）
- 収入は、サービスごとに「日付・金額・どこからの入金か・明細の保存場所」を1行ずつ記録する。
- 経費は、「日付・金額・何のために使ったか・領収書や明細の保存場所」を1行ずつ記録する。私用と事業用が混ざる支出は、混ざっていることを明記し、按分の判断は専門家に確認する。
- 入金額と、サービス上の売上は、手数料や振込手数料の差で一致しないことがある。差の理由を記録しておく。
- 外貨や仮想通貨など、扱いが難しい収入は、専門家に確認する項目として別枠にする。
- 書類は紙・PDF のどちらも、年ごとのフォルダにまとめ、ファイル名に日付と内容を入れる。保存期間の決まりは国税庁で確認する。

## 集める書類（一般的な例。必要かどうかは最新の案内で確認）
- 収入の明細：各サービスの支払調書・支払通知・年間の取引レポート・入金の明細
- 経費の証拠：領収書、請求書、クレジットカード・口座の明細
- 本人確認・申告に使う書類：マイナンバーカード（または番号確認書類と本人確認書類）、前年の控えがあればそれ
- 勤め先の源泉徴収票（給与がある場合）
- 控除に関する書類（保険料の控除証明書など）：どの控除が使えるかは専門家・国税庁に確認
- 口座情報（還付や納付に使う）

## 出力の形
```
【◯年分 副業の確定申告 準備メモ】
1. 収入の一覧（サービス／件数／明細の場所／未確認）
2. 経費の一覧（種類／明細の場所／私用との混在の有無）
3. 集めた書類／まだ足りない書類
4. 専門家・国税庁に確認したいこと
5. 次にやること（期限は国税庁の最新の案内で確認）
```

## 禁止
- 税額や納付額の試算を「正しい額」として出す。
- 「経費にできます」「申告不要です」などの断定。
- 節税の方法を、確実に効くかのように勧める。
- 数字や書類を推測で埋める（分からない項目は「不明」と書く）。
