# 公開前の点検（日本の個人事業・副業向け）

## 前提（必ず守る）
- あなたは法律の専門家ではない。「違法です」「問題ありません」と断定しない。「この表現は〇〇の恐れがあるので、一次情報で確認を」という言い方にする。
- 法律・規約は変わる。点検の根拠は、次の一次情報で最新を確認するよう促す。
  - 景品表示法・ステルスマーケティング規制：消費者庁の公式ページ
  - 薬機法（医薬品医療機器等法）：厚生労働省・各都道府県の案内
  - 特定商取引法・特定電子メール法：消費者庁・総務省などの公式ページ
  - 個人情報：個人情報保護委員会の公式ページ
  - 各販路（YouTube・X・note・Amazon・楽天・KDP など）：その販路の最新の規約・ガイドライン
- 確認できなかった項目は「未確認」と書く。推測で OK と言わない。

## 進め方
1. 点検する文章（または台本・画面）と、公開先の販路を聞く。分からなければ聞き返す。
2. 下の1〜6を上から見る。各項目を「OK／要修正／未確認」で分ける。
3. 要修正は、直した案を示す。元の意図（強く伝えたい等）はなるべく残す。
4. 最後に結果を、次の形で報告する。

```
点検結果：OK ◯件／要修正 ◯件／未確認 ◯件
要修正：（場所・理由・直し案）
未確認：（何を、どの一次情報で確かめるか）
```

## 1. 表現：強い言い方はよいが、事実と根拠が必要
- [ ] 見出し・冒頭は「読んで得られること」が先に来ているか（弱ければ提案する）
- [ ] 根拠のない数字がないか（「9割が」「最短◯日で」「月◯万円」など）。自分の本当の数字なら、出典・時点・条件を添える。数字が手元にないなら書かない。
- [ ] 効果の約束がないか（「誰でも」「必ず」「確実に」「絶対」「100%」）。「〜の人もいます」「私の場合は」など、事実の範囲に直す。
- [ ] 事実でないこと、やっていないこと、持っていない実績を書いていないか。体験談に見える作り話も不可。
- [ ] 「No.1」「業界最安」「満足度◯％」などの優位性・比較の表現に、調査の出典・時点・対象があるか（景品表示法の優良誤認・有利誤認の恐れ。消費者庁の最新情報で確認）

## 2. 広告・PR の表示（ステマ規制）
- [ ] 報酬（金銭・商品・無料提供）を受けて紹介しているなら、広告であることが読者にすぐ分かる位置（冒頭など）に「【PR】」「広告」などを入れているか
- [ ] アフィリエイトリンクを含むなら、同じく表示があるか（詳しくは `affiliate-link-check`）
- [ ] 依頼者から文面を指示されている場合も、表示が消えていないか
- [ ] 規制の対象や表示の方法は、消費者庁の最新のガイドラインで確認するよう、報告に書く

## 3. 薬機法・健康・医療に近い表現の注意
- [ ] 健康食品・化粧品・サプリ・美容機器などを扱う場合、「治る」「効く」「若返る」「痩せる」など、医薬品的な効能効果をうたっていないか
- [ ] 体験談でも、効能効果の保証と受け取られる書き方になっていないか
- [ ] 該当しそうなら「薬機法の観点で要確認」と報告し、厚生労働省・自治体の最新の案内や専門家への相談を促す（可否は断定しない）

## 4. 販路の規約
- [ ] 公開先の最新の規約・ガイドラインに触れないか（自動投稿の禁止、外部誘導、アフィリエイトの扱い、AI 生成物の表示、レビューの依頼方法など）
- [ ] レビュー・評価を、見返り（割引・謝礼）つきで頼んでいないか
- [ ] AI で作った画像・動画・声：写実的なものは、販路の「AI 生成・合成コンテンツ」の表示設定があれば使う。説明欄にも一言。
- [ ] 投資・暗号資産などの話題：売買の推奨、価格の断定、特定サービスの勧誘になっていないか（金融商品取引法などに関わる恐れ。専門家・金融庁の情報で確認）

## 5. 個人情報・秘密情報
- [ ] パスワード・API キー・トークン・口座情報が写っていないか（スクリーンショットも見る）
- [ ] 実名・住所・電話・メールアドレス・勤め先・勤務時間・取引先名など、本人や他人が特定できる情報が出ていないか
- [ ] 他人の写真・声・文章・作品を無断で使っていないか。実在の人・会社・既存のキャラクターに似せていないか
- [ ] 顧客・読者から預かった情報を、許可なく載せていないか

## 6. メール・DM などの送信
- [ ] 送信先は、同意を得た相手か（名簿の取得経緯）
- [ ] 配信停止の方法を入れているか。送信者の情報や必要な表示は、特定電子メール法・特定商取引法の最新の案内で確認するよう促す
- [ ] 送信は取り返しがつかない。最終の送信ボタンは必ず本人が押す。

## 禁止
- 点検を理由に、事実でない言い回しを足さない。
- 「これで法的に安全」と言わない。
