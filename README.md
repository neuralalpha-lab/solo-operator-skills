# 日本の個人事業・副業向け Claude Code スキル集（無料版）

個人で事業や副業をしている人が、Claude（claude.ai / Claude Code）に毎回同じ指示を書かなくて済むようにするための、小さなスキルの詰め合わせです。公開前の点検、小さな試しの設計、確定申告の準備メモ、アフィリエイト表示の点検の4本が入っています。

このスキルは「点検のための問いと手順」を渡すものです。法律や税の判断はしません。収益や効果を約束するものでもありません。

## 含まれるスキル

| スキル | 使う場面 |
|---|---|
| `jp-publish-check` | 記事・動画台本・投稿・出品文・メールを公開・送信する前の点検（景品表示法・ステマ規制の表示、根拠のない数字、薬機法の注意、販路の規約、個人情報） |
| `small-experiment` | 「新しい手を試したい」「試しの結果を判定したい」とき。2週間で測れる試しの作り方と記録の形 |
| `side-job-tax-memo` | 副業の確定申告に向けた、必要書類と記録の整理メモ作り（税額の計算・判断はしない） |
| `affiliate-link-check` | アフィリエイトのリンクと広告表示の点検 |

各スキルは `skills/<スキル名>/SKILL.md` にあります。

## 入れ方

### claude.ai（Web・アプリ）

1. 入れたいスキルのフォルダ（例：`skills/jp-publish-check`）を zip に固めます。zip の中身は、フォルダ直下に `SKILL.md` がある形にします。
2. claude.ai の設定のスキル（Skills）の画面で、zip をアップロードして有効にします。画面の名前や手順は変わることがあるので、最新は Anthropic の公式ヘルプを見てください。

### Claude Code

1. 使いたいプロジェクトの `.claude/skills/` に、スキルのフォルダをそのままコピーします（例：`.claude/skills/jp-publish-check/SKILL.md`）。
2. 全プロジェクトで使うなら、ホームの `~/.claude/skills/` に置きます。
3. Claude Code を開き直し、「公開前に点検して」などと頼むと、説明文に合うスキルが使われます。

## 使い方の例

- 「この記事を公開前に点検して」
- 「来週から投稿時間を変える試しを設計して」
- 「副業の確定申告に向けて、集める書類を一覧にして」
- 「このブログ記事のアフィリエイト表示を見て」

## ご注意

- 法律・税・各販路の規約は変わります。スキルは一般的な確認項目を並べているだけで、法的助言ではありません。事実の根拠は、消費者庁・国税庁・各販路の公式ページなど、最新の一次情報で確認してください。迷うときは専門家（弁護士・税理士など）に相談してください。
- Claude の出力は間違うことがあります。公開・送信・申告の前に、自分の目で確かめてください。
